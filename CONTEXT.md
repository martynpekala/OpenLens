# OpenLens

OpenLens is a native iOS companion app for OpenCode: it connects to an OpenCode server and lets a person follow and steer coding sessions from their phone.

## Language

**Detected link**:
A bare `http(s)://` or `www.` URL that appears in the prose, list, or blockquote text of a message, whether from the person or from the model. URLs inside code blocks are not detected links.
_Avoid_: Auto-link, URL match

**Release highlights**:
The short list of user-facing changes introduced by an OpenLens release, shown once to a person who updated from an earlier release. They describe the app, never the connected OpenCode server; a person installing OpenLens for the first time has no release highlights to see.
_Avoid_: What's New content, changelog, release notes, server features

**What's New sheet**:
The sheet that presents release highlights after the person connects to a server, and that can be reopened from Settings.
_Avoid_: Changelog screen, update popup
