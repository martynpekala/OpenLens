# OpenLens

OpenLens is a native iOS companion app for OpenCode: it connects to an OpenCode server and lets a person follow and steer coding sessions from their phone.

## Language

**Detected link**:
A bare `http(s)://` or `www.` URL that appears in the prose, list, or blockquote text of a message, whether from the person or from the model. URLs inside code blocks are not detected links.
_Avoid_: Auto-link, URL match
